# 10. Evaluation gates

Hard gates run before scoring. A failed or missing check yields no score. Design
requires manifest/hash invariants, context/trace locks, 100% evidence and
verification links, zero contradictions, zero Critical/High findings, and human
approval. Code additionally requires exact approved snapshot/version, isolation,
scope, compile/type/test success, contract/data/dependency integrity, regression
and performance evidence, and 100% requirement-code-test trace.

Passing requires fidelity 100, each core category ≥96, weighted score ≥99,
evidence coverage ≥99%, and no Critical/High finding. This only enters HUMAN_TEST.
Evaluators receive artifacts and raw evidence but not writer self-scores.
